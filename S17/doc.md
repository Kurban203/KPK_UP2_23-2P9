# Вариант №9. Сервис движения студентов (Student Movement Service)



### Информация, требуемая для создания Room

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| number | Номер аудитории (например, "101", "А-203", "Лаб-5") | Да | string | 1-20 символов | - |
| floor | Этаж, на котором расположена аудитория | Да | int | от 0 до 20 | - |
| building | Название или литера корпуса | Да | string | 1-50 символов | - |
| capacity | Вместимость аудитории (количество мест) | Да | int | от 1 до 500 | - |

### Уникальные комбинации параметров

| Комбинация | Пояснение |
|------------|-----------|
| (number, building) | В одном корпусе не может быть двух аудиторий с одинаковым номером |

### Информация, возвращаемая при успешном создании Room

| Параметр | Тип |
|----------|-----|
| id | int |
| number | string |
| floor | int |
| building | string |
| capacity | int |
| is_active | bool |

---

## Удаление Room по ID

**Возвращаемое значение:** `True` (bool) — если аудитория была помечена как удалённая

> Запись из БД физически не удаляется. Реализуется через булевое поле `is_active`. При удалении поле устанавливается в `False`.

## ER-диаграмма

Диаграмма находится в **3-й нормальной форме**.

### Описание таблицы ROOM

| Поле | Тип | Ограничение | Описание |
|------|-----|-------------|----------|
| id | INTEGER | PRIMARY KEY | Уникальный идентификатор |
| number | VARCHAR(20) | NOT NULL | Номер аудитории |
| floor | INTEGER | NOT NULL | Этаж |
| building | VARCHAR(50) | NOT NULL | Корпус |
| capacity | INTEGER | NOT NULL | Вместимость |
| is_active | BOOLEAN | NOT NULL, DEFAULT 1 | Активна ли запись |

**Уникальное ограничение:** `UNIQUE(number, building)`
