# Вариант №17. Сервис аудиторий (Room Service)

### 1. Добавить аудиторию (создание)
Информация требуемая для создания аудитории

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
| ----- | ----- | ----- | ----- | ----- | ----- |
| number | Номер аудитории | Обязательно | Строка | Уникальный в пределах корпуса, от 1 до 10 символов | |
| floor | Этаж | Обязательно | Целое число | от 0 до 50 | |
| building | Корпус | Обязательно | Строка | от 1 до 50 символов | |
| capacity | Вместимость | Обязательно | Целое число | от 1 до 500 | |

**Выходные данные**

Информация возвращаемая в случае удачного создания аудитории

| Параметр | Пояснение | Тип |
| :---- | :---- | :---- |
| id | ID аудитории | Целое число |
| number | Номер аудитории | Строка |
| floor | Этаж | Целое число |
| building | Корпус | Строка |
| capacity | Вместимость | Целое число |
| is_active | Статус (активна/удалена) | Булево значение |

### 2. Изменить аудиторию по ID
Информация, требуемая для изменения аудитории по ID

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- | :---- |
| number | Номер аудитории | Необязательно | Строка | Уникальный в пределах корпуса | NULL |
| floor | Этаж | Необязательно | Целое число | от 0 до 50 | NULL |
| building | Корпус | Необязательно | Строка | от 1 до 50 символов | NULL |
| capacity | Вместимость | Необязательно | Целое число | от 1 до 500 | NULL |

**Выходные данные**  
Информация, возвращаемая в случае успешного изменения

| Параметр | Пояснение | Тип |
| :---- | :---- | :---- |
| id | ID аудитории | Целое число |
| number | Номер аудитории | Строка |
| floor | Этаж | Целое число |
| building | Корпус | Строка |
| capacity | Вместимость | Целое число |
| is_active | Статус | Булево значение |

### 3. Удалить аудиторию по ID (soft delete)
Вернет, если аудитория удалена (деактивирована)

| Параметр | Тип | Сообщение |
| :---- | :---- | :---- |
| message | Строка | Аудитория удалена |

Вернет, если аудитория не удалена

| Параметр | Тип | Сообщение |
| :---- | :---- | :---- |
| message | Строка | Аудитория не найдена или уже удалена |

*Примечание: запись из БД физически не удаляется, меняется is_active = False*

Информация возвращаемая в случае успешного поиска аудитории по ID

### 5. Получить список аудиторий по заданным параметрам
Информация требуемая для получения списка аудиторий

| Параметр | Пояснение | Тип | Описание |
| :---- | :---- | :---- | :---- |
| building | Корпус | Строка | Фильтр по точному совпадению |
| floor_min | Минимальный этаж | Целое число | Фильтр "этаж не ниже" |
| floor_max | Максимальный этаж | Целое число | Фильтр "этаж не выше" |
| capacity_min | Минимальная вместимость | Целое число | Фильтр "вмещает не меньше" |
| number_contains | Часть номера | Строка | Поиск по частичному совпадению номера |
| is_active | Статус | Булево значение | Показывать только активные/удаленные |

*Все параметры необязательные*

Информация возвращается в виде списка аудиторий

| Параметр | Пояснение | Тип |
| :---- | :---- | :---- |
| id | ID аудитории | Целое число |
| number | Номер аудитории | Строка |
| floor | Этаж | Целое число |
| building | Корпус | Строка |
| capacity | Вместимость | Целое число |
| is_active | Статус | Булево значение |

### 6. Оборудование аудитории (связь многие-ко-многим)

#### Добавить тип оборудования

Информация требуемая для создания типа оборудования

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
| ----- | ----- | ----- | ----- | ----- | ----- |
| name | Название оборудования | Обязательно | Строка | Уникальный, от 1 до 100 символов | |

**Выходные данные**

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |

#### Привязать оборудование к аудитории

Информация требуемая для привязки

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
| :---- | :---- | :---- | :---- | :---- |
| room_id | ID аудитории | Обязательно | Целое число | Должен существовать |
| equipment_id | ID типа оборудования | Обязательно | Целое число | Должен существовать |

**Выходные данные** (при успешной привязке)

| Параметр | Тип |
| :---- | :---- |
| message | Строка |
| room_id | Целое число |
| equipment_id | Целое число |

#### Получить оборудование аудитории по ID аудитории

| Параметр | Пояснение | Тип |
| :---- | :---- | :---- |
| equipment_list | Список оборудования | Список строк |
