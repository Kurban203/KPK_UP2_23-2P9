# Вариант №17. Сервис аудиторий (Room Service)
**Группа:** 23-2П9  
**Оценка:** 3

## 1. Сущность «Аудитория» (Room)

### 1.1. Добавить аудиторию

**Информация, требуемая для создания аудитории:**

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| number | Номер аудитории | Обязательно | Строка | от 1 до 10 символов | - |
| floor | Этаж | Обязательно | Целое число | от 0 до 50 | - |
| building | Корпус | Обязательно | Строка | от 1 до 50 символов | - |
| capacity | Вместимость | Обязательно | Целое число | от 1 до 500 | - |

**Уникальные комбинации параметров:**
- `(number, building)` — в одном корпусе не может быть двух аудиторий с одинаковым номером

**Выходные данные при успешном создании:**

| Параметр | Тип |
|----------|-----|
| id | Целое число |
| number | Строка |
| floor | Целое число |
| building | Строка |
| capacity | Целое число |
| is_active | Булево значение |

### 1.2. Изменить аудиторию по ID

**Информация, требуемая для изменения аудитории:**

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| number | Номер аудитории | Нет | Строка | от 1 до 10 символов | - |
| floor | Этаж | Нет | Целое число | от 0 до 50 | - |
| building | Корпус | Нет | Строка | от 1 до 50 символов | - |
| capacity | Вместимость | Нет | Целое число | от 1 до 500 | - |

**Выходные данные при успешном изменении:**

| Параметр | Тип |
|----------|-----|
| id | Целое число |
| number | Строка |
| floor | Целое число |
| building | Строка |
| capacity | Целое число |
| is_active | Булево значение |


### 1.3. Удалить аудиторию по ID (мягкое удаление)

Вернет `True`, если аудитория была помечена как удалённая, иначе `False`.

Фактически запись из БД не удаляется, а реализуется через булевое поле `is_active`.

### 1.4. Получить аудиторию по ID

**Выходные данные:**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| id | ID аудитории | Целое число |
| number | Номер аудитории | Строка |
| floor | Этаж | Целое число |
| building | Корпус | Строка |
| capacity | Вместимость | Целое число |
| is_active | Статус активности | Булево значение |


### 1.5. Получить список аудиторий по параметрам

**Параметры фильтрации:**

| Параметр | Пояснение | Тип | Описание |
|----------|-----------|-----|----------|
| building | Корпус | Строка | Фильтр по корпусу |
| floor | Этаж | Целое число | Фильтр по этажу |
| min_capacity | Минимальная вместимость | Целое число | Вместимость >= значение |
| is_active | Статус активности | Булево | True/False |

**Выходные данные (список):**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| id | ID аудитории | Целое число |
| number | Номер аудитории | Строка |
| floor | Этаж | Целое число |
| building | Корпус | Строка |
| capacity | Вместимость | Целое число |
| is_active | Статус активности | Булево значение |


## 2. Сущность «Оборудование» (Equipment)

### 2.1. Добавить оборудование

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| name | Название оборудования | Обязательно | Строка | от 1 до 100 символов | - |

**Выходные данные при успешном создании:**

| Параметр | Тип |
|----------|-----|
| id | Целое число |
| name | Строка |

### 2.2. Связать оборудование с аудиторией

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| room_id | ID аудитории | Обязательно | Целое число | Должен существовать | - |
| equipment_id | ID оборудования | Обязательно | Целое число | Должен существовать | - |
| count | Количество | Нет | Целое число | от 1 до 100 | 1 |

### 2.3. Получить оборудование аудитории по ID аудитории

**Выходные данные:**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| equipment_list | Список оборудования в аудитории | Список |

## 3. ER-диаграмма

Диаграмма находится в **3-й нормальной форме**. Связь «многие ко многим» реализована через транзитивную таблицу `room_equipment`.

![ER-диаграмма](erd.png)

## 4. Связи между таблицами

| Таблица 1 | Таблица 2 | Тип связи | Транзитивная таблица |
|-----------|-----------|-----------|---------------------|
| Room | Equipment | Многие ко многим | room_equipment |

## 5. Мягкое удаление

Реализовано через поле `is_active`:
- `is_active = True` — запись активна
- `is_active = False` — запись удалена (скрыта)
