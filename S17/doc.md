# Вариант №17. Сервис аудитории.

## 1. Сущность «Аудитория» (Room)

### 1.1. Добавить аудиторию

**Информация, требуемая для создания аудитории:**

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| number | Номер аудитории | Обязательно | Строка | Уникальный в пределах корпуса, от 1 до 10 символов | |
| floor | Этаж | Обязательно | Целое число | от 0 до 25 | |
| building | Корпус | Обязательно | Строка | от 1 до 5 символов | |
| capacity | Вместимость | Обязательно | Целое число | от 1 до 500 | |
| room_type | Тип аудитории | Обязательно | Строка | cabinet, lab, workshop | |

**Выходные данные при успешном создании:**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| id | ID аудитории | Целое число |
| number | Номер аудитории | Строка |
| floor | Этаж | Целое число |
| building | Корпус | Строка |
| capacity | Вместимость | Целое число |
| room_type | Тип аудитории | Строка |
| is_active | Статус активности | Булево значение |

|----------|-----------|-----|----------|

|----------|-----|

## 2. Сущность «Оборудование» (Equipment)

### 2.1. Добавить оборудование

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
|----------|-----------|----------------|-----|-------------|
| name | Название | Обязательно | Строка | Уникальное, 1-50 символов |
| type | Тип | Обязательно | Строка | projector, board, pc, etc. |

### 2.2. Связь аудитории с оборудованием (многие ко многим)

**Транзитивная таблица `room_equipment`:**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| room_id | ID аудитории | Целое число |
| equipment_id | ID оборудования | Целое число |
| count | Количество | Целое число (>=1) |

## 3. ER-диаграмма

Диаграмма находится в **3-й нормальной форме**. Связь «многие ко многим» реализована через транзитивную таблицу `room_equipment`.

![ER-диаграмма](erd.png)

## 4. Уникальные комбинации

- `(number, building)` — в одном корпусе не может быть двух одинаковых номеров аудиторий

## 5. Мягкое удаление

Реализовано через поле `is_active`:
- `is_active = True` — запись активна
- `is_active = False` — запись удалена (скрыта)
