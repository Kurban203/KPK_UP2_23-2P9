## 1. Сущность «Аудитория» (Room)

### 1.1. Создание аудитории

**Информация, требуемая для создания аудитории:**

| Параметр (англ.) | Пояснение (рус.) | Обязательность | Тип | Ограничение | Значение по умолчанию |
|-----------------|------------------|----------------|-----|-------------|----------------------|
| number | Номер аудитории | Да | string | длина от 1 до 10 символов | - |
| floor | Этаж | Да | integer | от 0 до 25 | - |
| building | Корпус | Да | string | длина от 1 до 5 символов | - |
| capacity | Вместимость | Да | integer | от 1 до 500 | - |
| room_type | Тип аудитории | Да | enum | cabinet, lab, workshop | - |

**Уникальные комбинации параметров:**
- `(number, building)` — в одном корпусе не может быть двух аудиторий с одинаковым номером

**Информация, возвращаемая при успешном создании:**

| Параметр (англ.) | Тип |
|-----------------|-----|
| id | integer |
| number | string |
| floor | integer |
| building | string |
| capacity | integer |
| room_type | string |
| is_active | boolean |

### 1.2. Изменение аудитории по ID

**Информация, требуемая для изменения аудитории:**

| Параметр (англ.) | Пояснение (рус.) | Обязательность | Тип | Ограничение | Значение по умолчанию |
|-----------------|------------------|----------------|-----|-------------|----------------------|
| number | Номер аудитории | Нет | string | длина от 1 до 10 символов | - |
| floor | Этаж | Нет | integer | от 0 до 25 | - |
| building | Корпус | Нет | string | длина от 1 до 5 символов | - |
| capacity | Вместимость | Нет | integer | от 1 до 500 | - |
| room_type | Тип аудитории | Нет | enum | cabinet, lab, workshop | - |

**Информация, возвращаемая при успешном изменении:**

| Параметр (англ.) | Тип |
|-----------------|-----|
| id | integer |
| number | string |
| floor | integer |
| building | string |
| capacity | integer |
| room_type | string |
| is_active | boolean |

### 1.3. Удаление аудитории по ID

**Возвращаемое значение:**
- `true` — если аудитория была помечена как удалённая
- `false` — если аудитория не найдена или уже удалена

**Примечание:** Фактического удаления из БД не происходит. Реализуется через булево поле `is_active` (при удалении устанавливается `false`).

### 1.4. Получение аудитории по ID

**Информация, возвращаемая при успешном поиске:**

| Параметр (англ.) | Пояснение (рус.) | Тип |
|-----------------|------------------|-----|
| id | Уникальный идентификатор аудитории | integer |
| number | Номер аудитории | string |
| floor | Этаж | integer |
| building | Корпус | string |
| capacity | Вместимость | integer |
| room_type | Тип аудитории | string |
| is_active | Статус активности (не удалена ли запись) | boolean |

### 1.5. Получение списка аудиторий по параметрам

**Параметры для фильтрации:**

| Параметр (англ.) | Пояснение (рус.) | Тип | Описание |
|-----------------|------------------|-----|----------|
| building | Корпус | string | Фильтр по корпусу (точное совпадение) |
| floor | Этаж | integer | Фильтр по этажу (точное совпадение) |
| room_type | Тип аудитории | string | Фильтр по типу (cabinet, lab, workshop) |
| min_capacity | Минимальная вместимость | integer | Вместимость >= указанного значения |
| is_active | Статус активности | boolean | true — только активные, false — удалённые |

**Информация, возвращаемая в виде списка:**

| Параметр (англ.) | Тип |
|-----------------|-----|
| id | integer |
| number | string |
| floor | integer |
| building | string |
| capacity | integer |
| room_type | string |
| is_active | boolean |

## 2. Связь «многие ко многим»

### 2.1. Сущность «Оборудование» (Equipment)

Связь между аудиториями и оборудованием реализована через транзитивную таблицу.

#### Создание оборудования

| Параметр (англ.) | Пояснение (рус.) | Обязательность | Тип | Ограничение | Значение по умолчанию |
|-----------------|------------------|----------------|-----|-------------|----------------------|
| name | Название оборудования | Да | string | уникальное, длина 1-50 | - |
| type | Тип оборудования | Да | string | projector, board, pc, etc. | - |

### 2.2. Транзитивная таблица `room_equipment`

| Параметр (англ.) | Пояснение (рус.) | Тип | Ограничение |
|-----------------|------------------|-----|-------------|
| room_id | ID аудитории | integer | Внешний ключ → Room.id |
| equipment_id | ID оборудования | integer | Внешний ключ → Equipment.id |
| count | Количество единиц | integer | >= 1 |

**Уникальная комбинация:** `(room_id, equipment_id)`

## 3. ER-диаграмма

Диаграмма находится в 3-й нормальной форме. Связь «многие ко многим» между аудиториями и оборудованием реализована через транзитивную таблицу `room_equipment`.
